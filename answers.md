**1. State and Explain the Components of a DBMS (Database Management System)**
Storage Engine: Manages how data is stored and retrieved.
Query Processor: Interprets and executes SQL queries.
Transaction Manager: Ensures database transactions follow ACID properties 
Metadata Catalog: Stores information about the database structure 
Security Manager: Controls user access and permissions.
2. **What is a Relational Database? Give 4 Examples.**
A relational database organizes data into tables (relations) with rows and columns, linked by keys, examples of relational databases are (a) MYSQL (b) PostgreSQL (c) Oracle Database (d) Microsoft SQL Server
**3.State and Explain Three Classifications of SQL****
DDL (Data Definition Language): Commands that define database structure 

DML (Data Manipulation Language): Commands for managing data
DCL (Data Control Language): Commands for permissions 
**4. Difference Between a Primary Key and a Foreign Key**
Primary Key: Uniquely identifies a row in a table 
Foreign Key: Links to a Primary Key in another table to enforce relationships
**5.What is an Entity-Relationship Diagram (ERD)?**
An ERD is a visual representation of database entities (tables), their attributes (columns), and relationships. Tools like MySQL or Workbench  create ERDs.
**6. Advantages of Relational Databases**
Data Integrity: Constraints prevent invalid data.
Flexibility: Easy to query with SQL.
Scalability: Handles large datasets efficiently.
Security: User access controls.
**7. State four types of data types used to store data in tables**.
INTEGER: Used to store whole numbers.
VARCHAR: Used to store variable-length strings of characters.
DATE: Used to store date values.
FLOAT: Used to store decimal numbers.
**8. Purpose of a Database Management System (DBMS)**
Storing and retrieving data efficiently.
Ensuring data security and integrity.
Supporting multi-user access without conflicts.
Providing backup/recovery options.
